# Граф зависимостей для менеджера пакетов. Этап 1: минимальный прототип с конфигурацией

## 1. Общее описание

Консольное приложение (CLI) для визуализации графа зависимостей пакета.
На этапе 1 приложение читает настраиваемые параметры из YAML-файла,
проверяет их и выводит в формате ключ-значение. Если в файле есть ошибка,
приложение сообщает о ней и завершается.

## 2. Описание функций и настроек

### Функции (src/main.py)

- `ConfigError` - класс исключения для ошибок в конфигурации.
- `load_config(path)` - открывает YAML-файл и возвращает словарь
  параметров. Выбрасывает `ConfigError`, если файл не открывается,
  содержит некорректный YAML или не является набором ключ-значение.
- `check_type(name, value)` - проверяет, что значение параметра имеет
  нужный тип. При несовпадении выбрасывает `ConfigError`.
- `validate_config(config)` - проверяет, что заданы все параметры, что у них
  верные типы, что строки не пустые, а глубина не меньше 1.
- `print_params(config)` - выводит все параметры в формате `ключ: значение`.
- `main()` - точка входа: разбирает аргументы командной строки, читает и
  проверяет конфигурацию, выводит параметры. При ошибке печатает сообщение
  `Ошибка: ...` и завершает работу.

### Аргументы командной строки

- `-c`, `--config` - путь к YAML-файлу. По умолчанию `config.yaml`.

### Параметры config.yaml

Параметр - Тип - Описание

- package_name - строка - Имя анализируемого пакета (не пустое)
- repository_url - строка - URL репозитория или путь к файлу тестового репозитория (не пустая)
- test_mode - true/false - Режим работы с тестовым репозиторием
- ascii_tree - true/false - Вывод зависимостей в формате ASCII-дерева
- max_depth - целое число - Максимальная глубина анализа (>= 1)
- filter_substring - строка - Подстрока для фильтрации пакетов

## 3. Команды для сборки и запуска тестов

Сборка не требуется, но нужно установить зависимости:

    pip install -r requirements.txt

Запуск тестов:

    python3 -m unittest discover -s tests -t .

На Windows вместо `python3` - `python` или `py`.

## 4. Примеры использования

Запуск с конфигурацией по умолчанию (Linux/macOS):

    sh run.sh

Запуск на Windows:

    run.bat

Запуск с указанием файла:

    sh run.sh -c my_config.yaml

Пример config.yaml:

    package_name: requests
    repository_url: https://example.com/repo
    test_mode: false
    ascii_tree: true
    max_depth: 3
    filter_substring: test

Вывод программы:

    package_name: requests
    repository_url: https://example.com/repo
    test_mode: False
    ascii_tree: True
    max_depth: 3
    filter_substring: test

Примеры ошибок:

    $ sh run.sh -c nope.yaml
    Ошибка: Не удалось открыть файл: ...

    # в конфигурации удалён параметр max_depth
    Ошибка: Не задан параметр 'max_depth'

    # в конфигурации max_depth: abc
    Ошибка: Параметр 'max_depth' должен иметь тип int

    # в конфигурации max_depth: 0
    Ошибка: Параметр 'max_depth' должен быть >= 1
