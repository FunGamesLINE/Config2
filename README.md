# Граф зависимостей для менеджера пакетов. Этап 5: визуализация

## 1. Общее описание

Консольное приложение для визуализации графа зависимостей пакета.
Приложение читает параметры из YAML-файла и строит граф зависимостей
пакета Rust (Cargo) с учётом транзитивности. Граф строится обходом в
ширину с рекурсией, с учётом максимальной глубины, фильтра по подстроке
и циклических зависимостей. Есть тестовый режим, в котором граф
берётся из файла, а пакеты называются большими латинскими буквами.
Поддерживается режим обратных зависимостей: вывод пакетов, которые
зависят от заданного. Граф выводится в виде текста, ASCII-дерева
(если ascii_tree: true), текста на языке PlantUML и изображения.
Изображение строится публичным сервером plantuml.com, оно сохраняется
в graph.png.
Требуется Python 3.11 или новее и подключение к интернету для построения
изображения и просмотра репозитория по ссылке.

## 2. Описание функций и настроек

### Функции (src/main.py)

- `ConfigError` - исключение для ошибок конфигурации и получения данных.
- `load_config(path)` - читает YAML-файл и возвращает словарь параметров.
- `check_type(name, value)` - проверяет тип значения параметра.
- `validate_config(config)` - проверяет наличие, типы и значения параметров.
- `make_manifest_url(repository_url)` - строит ссылку на Cargo.toml
  в корне репозитория GitHub.
- `read_local_file(path)` - читает тестовый файл с диска.
- `download_text(url)` - скачивает текстовый файл по ссылке.
- `read_manifest_text(config)` - возвращает текст тестового файла или
  Cargo.toml из репозитория.
- `get_version(spec)` - возвращает версию из описания зависимости.
- `get_dependencies(text)` - разбирает Cargo.toml и возвращает прямые
  зависимости (раздел [dependencies]).
- `parse_graph(text)` - разбирает файл тестового графа.
- `fetch_json(url)` - скачивает и разбирает JSON.
- `get_latest_version(name)` - возвращает последнюю версию пакета
  из crates.io.
- `fetch_crate_dependencies(name)` - возвращает имена зависимостей
  последней версии пакета из crates.io.
- `load_source(config)` - готовит словарь пакет - зависимости с корневым
  пакетом.
- `get_children(source, name, test_mode)` - возвращает зависимости пакета,
  при необходимости загружая их, с учётом обратного режима.
- `is_skipped(name, substring)` - проверяет, содержит ли имя подстроку.
- `build_graph(level, graph, source, config, depth)` - строит граф обходом
  в ширину; каждый рекурсивный вызов обрабатывает один уровень.
- `print_graph(package_name, graph)` - выводит граф, с учётом обратного режима.
- `invert_graph(graph)` - разворачивает граф: пакет - список пакетов, зависящих от него.
- `fetch_reverse_dependencies(name)` - возвращает имена пакетов, зависящих от пакета, из crates.io.
- `download_bytes(url)` - скачивает файл по ссылке и возвращает его содержимое.
- `add_tree_lines(graph, name, prefix, shown, lines)` - рекурсивно добавляет строки ASCII-дерева.
- `make_ascii_tree(root, graph)` - возвращает текст ASCII-дерева.
- `collect_names(graph)` - возвращает все пакеты графа без повторов.
- `get_edges(graph, reverse_mode)` - возвращает рёбра графа.
- `make_plantuml(graph, reverse_mode)` - формирует текст диаграммы PlantUML.
- `encode_plantuml(text)` - кодирует текст диаграммы для адреса сервера PlantUML.
- `show_image(plantuml_text)` - скачивает, сохраняет и открывает изображение.
- `show_results(config, graph)` - выводит все результаты.
- `main()` - точка входа. При ошибке печатает `Ошибка: ...` и завершается.

### Аргументы командной строки

- `-c`, `--config` - путь к YAML-файлу. По умолчанию `config.yaml`.

### Параметры config.yaml

- package_name - имя анализируемого пакета (строка, не пустая)
- repository_url - URL репозитория GitHub или, в тестовом режиме, путь
  к файлу описания графа (строка, не пустая)
- test_mode - режим тестового репозитория (true/false)
- reverse_mode - режим обратных зависимостей (true/false): вместо
  зависимостей пакета выводятся пакеты, которые от него зависят.
  Строка D: B C означает, что от D зависят B и C.
- ascii_tree - вывод в формате ASCII-дерева (true/false), (*) означает, 
  что пакет уже раскрыт выше.
- max_depth - максимальная глубина анализа (целое число >= 1): 1 - только
  прямые зависимости, 2 - ещё и их зависимости, и т. д.
- filter_substring - пакеты, в имени которых есть эта подстрока (с учётом
  регистра), не анализируются. Пустая строка - без фильтра. На корневой
  пакет фильтр не действует.

## 3. Команды для сборки и запуска тестов

Сборка не требуется, но нужно установить зависимости:

    python -m pip install -r requirements.txt

Запуск тестов:

    python -m unittest discover -s tests -t .

Демонстрация тестового репозитория (все случаи, Windows):

    tests\test.bat

## 4. Примеры использования

Запуск с конфигурацией по умолчанию (реальный репозиторий):

    run.bat
    sh run.sh

Запуск с тестовым репозиторием:

    run.bat -c tests\test_config.yaml

Файл tests/test_graph.txt:

    A: B C
    B: D
    C: D E
    D: F
    E:
    F:
    X: Y
    Y: Z
    Z: X

Полный граф (tests/test_config.yaml, max_depth: 10):

    Граф зависимостей пакета A:
    A: B C
    B: D
    C: D E
    D: F
    E: нет
    F: нет

Ограничение глубины (tests/test_depth.yaml, max_depth: 2):

    Граф зависимостей пакета A:
    A: B C
    B: D
    C: D E

Фильтр по подстроке (tests/test_filter.yaml, filter_substring: "D"):

    Граф зависимостей пакета A:
    A: B C
    B: нет
    C: E
    E: нет

Цикл (tests/test_cycle.yaml, package_name: X):

    Граф зависимостей пакета X:
    X: Y
    Y: Z
    Z: X

Несуществующий пакет (tests/test_error.yaml, package_name: X):

    Ошибка: Пакет 'Q' не найден в файле графа

Полный граф в обратном режиме (tests/test_reverse.yaml, max_depth: 10):

    F: D
    D: B C
    B: A
    C: A
    A: нет

Ограничение глубины в обратном режиме (tests/test_reverse_depth.yaml, max_depth: 2):

    F: D
    D: B C

Фильтр по подстроке в обратном режиме (tests/test_reverse_filter.yaml, filter_substring: "B"):

    F: D
    D: C
    C: A
    A: нет

Цикл в обратном режиме (tests/test_reverse_cycle.yaml, package_name: X):

    X: Z
    Z: Y
    Y: X

Отсутствие обратных зависимостей (tests/test_reverse_none.yaml, package_name: A):

    A: нет

Примеры ошибок:

    Ошибка: Пакет 'Q' не найден в файле графа
    Ошибка: Не удалось открыть файл: ...
    Ошибка: Поддерживаются только репозитории GitHub
    Ошибка: Не удалось скачать https://...: HTTP Error 404: Not Found
